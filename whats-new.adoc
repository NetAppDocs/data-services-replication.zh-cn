[[06-october-2025]]
== 2025年10月6日



[[bluexp-replication-is-now-netapp-replication]]
=== BlueXP replication现已更名为NetApp Replication

BlueXP replication已重命名为NetApp Replication。



[[bluexp-is-now-netapp-console]]
=== BlueXP现在是NetApp Console

NetApp Console建立在增强和重组的BlueXP基础之上，可在企业级内部和云环境中集中管理NetApp存储和NetApp Data Services，提供实时洞察、更快的工作流程和简化的管理，并且高度安全且合规。

有关更改的详细信息，请参见 link:https://docs.netapp.com/us-en/console-relnotes/index.html["NetApp Console发行说明"]。



[[18-september-2022]]
== 2022年9月18日



[[fsx-for-ontap-to-cloud-volumes-ontap]]
=== FSx for ONTAP到Cloud Volumes ONTAP

您现在可以将数据从Amazon FSx for ONTAP文件系统复制到Cloud Volumes ONTAP。

link:https://docs.netapp.com/us-en/data-services-replication/task-replicating-data.html["了解如何设置数据复制"]。



[[31-july-2022]]
== 2022年7月31日



[[fsx-for-ontap-as-the-data-source]]
=== FSx for ONTAP作为数据源

您现在可以将数据从Amazon FSx for ONTAP文件系统复制到以下目标：

* 适用于ONTAP 的Amazon FSx
* 本地ONTAP集群


link:https://docs.netapp.com/us-en/data-services-replication/task-replicating-data.html["了解如何设置数据复制"]。

link:https://docs.netapp.com/us-en/data-services-replication/task-replicating-data.html["了解如何设置数据复制"]。
